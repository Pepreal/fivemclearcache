## 🚀 FiveM Cache Cleaner (V0.3.2)

This is a standalone, lightweight desktop application built with Python and Tkinter designed to simplify and automate the process of cleaning up various cache and data files generated by **FiveM**. It aims to solve common issues like client-side crashes, texture glitches, and loading errors by ensuring a clean game environment before launch.

### ✨ Key Features

* **Automated Cache Detection:** Automatically searches common locations (`%LOCALAPPDATA%` and all mounted drives) to find the correct FiveM installation path (`FiveM.app/data`).
* **Dynamic Size Calculation:** Instantly scans and displays the size of the cache and data folders, updating the total size based on the chosen cleanup mode.
* **Two Cleanup Modes:** Offers flexible cleaning options for basic troubleshooting and deep resets.
    * **1. Essential Cache Clean (Default):** Safely removes temporary files like **`cache`**, **`logs`**, **`crashes`**, **`server-cache`**, and **`server-cache-priv`**.
    * **2. Deep Clean (Optional):** Performs the Essential Cache Clean **PLUS** removes user login details and local game settings (**`nui-storage`** and **`game-storage`**). **(Requires re-login to FiveM)**.
* **Forced Launch Mode:** Allows the user to launch FiveM with the **`-pure_1`** argument for strict server environments or advanced troubleshooting.
* **Live Logging:** Provides a detailed log of the discovery, deletion, and launch processes for transparency and debugging.

---

### ⚙️ How It Works

The application operates in a simple three-step process:

1.  **Search:** The **"Search for FiveM Cache"** button locates the `FiveM.app/data` folder and scans the size of all targeted subdirectories.
2.  **Clean:** Based on whether the **"Deep Clean"** option is checked, the appropriate set of folders is recursively deleted using `shutil.rmtree`.
3.  **Launch (Optional):** After cleaning, the user is prompted to launch `FiveM.exe`. If the **"Force Pure Mode"** option is checked, the argument `-pure_1` is added to the launch command.

---

### 🛠️ Usage (For End-Users)

1.  **Close FiveM:** Ensure the FiveM client is completely closed.
2.  **Run the Tool:** Execute the application.
3.  **Search:** Click **"Search for FiveM Cache"** to automatically locate your installation and calculate the cache size.
4.  **Select Mode:**
    * For a quick fix, leave **"Deep Clean"** unchecked.
    * To clear login data and settings, check **"Deep Clean"** (You will need to re-log in).
5.  **Clean:** Click **"Start Cleanup"**.
6.  **Launch:** Choose whether to launch FiveM in Normal or Pure Mode after the cleanup is complete.

### 💻 Technical Details (For Developers)

The script is a single-file application written in Python 3.

* **GUI:** Built using the standard library `tkinter` and `ttk` for a native look-and-feel (including basic Windows Dark/Light mode detection).
* **Dependencies:** Uses only **standard Python libraries**: `os`, `shutil`, `sys`, `subprocess`, `tkinter`, `winreg` (Windows only), and `ctypes` (Windows only).
* **Core Logic:** Folder size calculation is performed iteratively using `os.walk` to prevent memory issues with very large cache folders.
* **Deletion:** Uses `shutil.rmtree` within a `try...except` block to safely handle potential permission errors (e.g., if FiveM is still running).
